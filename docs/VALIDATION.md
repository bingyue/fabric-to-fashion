# 验收记录

环境：macOS，Node.js 22.23.1，Next.js 16.4.0，React 19.3.0。验收日期：2026-10-09（Asia/Shanghai）。

- 安装依赖、TypeScript 检查与生产构建成功。
- 生产依赖审计：0 个已报告漏洞。
- Playwright 完整流程：上传真实文件 → Demo 分析 → 修改档案 → 六款系列 → 修改说明 → 单款调整 → 版本记录 → 刷新保留 → PDF / ZIP 下载 → 收藏。
- 390×844 移动布局、导航、四款生成、放大弹窗与提案验证，无水平溢出。
- 8 款任务返回 8 个不同的预置图地址；请求 16:9 时 Demo 图保留原图并明确示例来源。
- 无效图片、无面料生成、跨会话访问、跨站写入与不安全 API 地址均被拒绝。
- GET 设置与保存响应不含 Key；磁盘配置不含明文 Key。
- 本地 HTTP Provider 合约覆盖 Gemini / OpenAI / Seedream 的图文输入、Base64 输出、原图编辑与错误脱敏。
- 真实任务引擎通过本地 mock 验证：四款中一款失败时保留三款，重试仅发起一款请求；服务重启中断状态可恢复为重试。
- 六款 PDF 为 13 页 A4 横版，包含封面、理念、面料档案、需求、六款详情、两页系列陈列、使用说明，中文字体内嵌并可提取文字。已将 PDF 渲染为图片检查排版。

未验证项：没有真实 API Key，未执行云端付费生图。真实模型的面料一致性、局部编辑保真度、提供商地域连通性与账户权限需要配置自己的 Key 后验证。没有部署到公共互联网，没有多租户账户 / 团队权限 / 商业计费体系。

复现命令参见 README。`output/` 中的图片与 PDF 为自动化验收产物；不会被当作真实用户任务结果。
